## Code Example

```javascript
class Character {
    constructor(name) {
        this.name = name
        this.collectedItems = []
    }

    addItem(item) {
        this.collectedItems.push(item)
        return `${this.name} now has: ${this.collectedItems.join(', ')}`
    }
}

const player = new Character('Player')

player.addItem('sword')
player.addItem('shield')
```
